# ADR-017: Localization and design/asset contracts

Status: Accepted
Date: 2026-11-06

- Canonical language EN, initial TR. New languages through reviewed PRs with full parity.
- Shared semantic design tokens and UI wrappers, separate Kids/Adult themes.
- Shared icon and licensed asset registries; no ad hoc paths or silent asset redistribution.
- Contract versions change with breaking interface/schema changes.
