# Robot Maze page contract

Audience: kids 6–8; adaptable for 9–12.
Localized keys: kids and challenges namespaces; EN/TR required.
States: ready, editing, running, failed, completed, local-save-error.
Accessible keyboard/touch control, motion reduction and no account required.
Business flow: command list → deterministic task evaluation → first-completion XP → local progress save.
No cloud sync or parent login is required for this exercise.
Tests: success, wall-hit, empty steps, XP idempotence, refresh persisted, EN/TR rendering, no adult navigation.
