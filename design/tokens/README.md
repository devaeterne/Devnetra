# Design System v1.0.0
Token source of truth: packages/design-tokens/src/index.ts.
Kids: vivid, fun, game-oriented; adult: restrained technological theme.
All pages use semantic CSS variables exposed by packages/design-tokens/styles.css. Contrast reviewed for text/button combinations, avoid using accent colors for small text without checks.
Use only documented space, radius and icon sizing scales.
Breaking changes require design-system version change and local CI review.
