# Devnetra

Open-source technology learning and engineering platform.

## Products
- **Devnetra Kids** (ages 6–12): algorithms, logic, creative coding; browser and standalone mobile app.
- **Devnetra** (adult): programming and Web3 engineering; browser and standalone mobile app.

## Engineering principles
- One public pnpm/Turborepo monorepo.
- English and Turkish first; new languages via reviewed translation PRs.
- Local-first CI; no heavy GitHub Actions jobs.
- Shared contracts, platform-specific interfaces, centrally versioned design tokens and assets.
- Kids can try without an account; adult Google/Apple sign-in enables optional parent-managed profiles and cloud backup.

Status: foundation bootstrap in progress. No production applications or cloud integrations are deployed.
